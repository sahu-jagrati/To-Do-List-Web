📝 To-Do List Web App

📌 About

A simple and responsive To-Do List web application built using HTML, CSS, and JavaScript. It allows users to manage daily tasks efficiently with persistent storage using localStorage.

🌍 Live Demo:
👉 https://sahu-jagrati.github.io/To-Do-List-Web/

✨ Features:
✅ Add tasks
❌ Delete tasks
✔️ Mark tasks as completed
💾 Data stored using localStorage
🎨 Clean and minimal UI

🛠️ Tech Stack:
HTML
CSS
JavaScript
